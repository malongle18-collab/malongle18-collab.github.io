# Recipe photo credits

Photos are stored in git as text `.jpg.b64` sidecars because the GitHub file API used to publish this site is text-oriented. The GitHub Pages workflow decodes them into the `.jpg` files the app loads. The same JPEGs are kept locally in this folder for development.

Photos for the built-in recipe library of 外傭僱傭助手. Files are hosted in this folder and are not hotlinked at runtime.

Allowed sources: Wikimedia Commons (and Wikipedia files with a clear free license), Unsplash, Pexels, Pixabay, or original illustrative photos generated for this app when no acceptable free photo could be found.
